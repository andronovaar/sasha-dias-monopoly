# Sasha & Dias Monopoly

Персональная браузерная настольная игра для двух игроков. Игровые суммы условные; стартовый капитал — 1 500 каждому, поле — 40 клеток. Игра заканчивается банкротством, таймера нет.

## Что реализовано в локальной версии

- Бросок двух кубиков, повторный бросок при дубле и отправление в тюрьму после трёх дублей подряд.
- Покупка недвижимости и аренда улиц, вокзалов и коммунальных предприятий.
- Цветовые группы и строительство домов после сбора группы. Дома можно строить неравномерно — по вашему правилу.
- Обмен четырёх домов на отель, продажа зданий и продажа недвижимости банку.
- Залог и выкуп недвижимости.
- Аукционы включаются после покупки 18 из 28 объектов. До этого отказавшийся от покупки объект остаётся у банка; после включения аукционов отказ или невозможность оплатить полную цену запускает торги.
- Обработка долга: можно продать здания или заложить имущество, чтобы оплатить его; банкротство доступно, если ликвидируемого имущества не хватает.
- Карточки «Шанс» и «Общественная казна», налоги, стартовая выплата и журнал действий.
- Базовый обмен недвижимостью с денежной доплатой между игроками на одном устройстве.

## Как запустить

1. Распакуй архив.
2. Открой `index.html` в современном браузере.
3. Игра локальная: Саша и Диас по очереди играют на одном устройстве. Установка не требуется.

Если браузер не запускает локальные файлы как ожидается, из папки проекта можно запустить простой сервер:

```bash
python3 -m http.server 8000
```

После этого открой `http://localhost:8000`.

## Проверка логики

Если на компьютере установлен Node.js, запусти из папки проекта:

```bash
node tests/smoke_test.js
```

Тест проверяет стартовый баланс, 40 клеток, строительство, аренду, ограничения залога, получение денег по залогу, погашение долга и базовый сценарий аукциона.

## Онлайн-режим — экспериментальный

В интерфейсе есть заготовка подключения к Supabase Realtime Broadcast. Она ещё не является надёжным полноценным онлайн-режимом: состояние может конфликтовать, если оба устройства одновременно отправят действия; нет серверного контроля ходов и защиты от некорректных изменений. До игры по интернету нужно отдельно доработать и протестировать синхронизацию.

Если решишь настраивать Supabase, используй только публичный `anon`/`publishable` key. Никогда не вставляй `service_role` key в браузерный код.

## Файлы

- `index.html` — интерфейс.
- `style.css` — оформление.
- `app.js` — игровая логика.
- `economy_v1.md` — таблицы цен, аренды и правила экономики.
- `tests/smoke_test.js` — тесты основных сценариев.
- `supabase/schema.sql` — ранняя заготовка схемы для дальнейшего онлайн-режима.


## Игра с двух разных устройств (Supabase Realtime)

### Что нужно
- Публичная ссылка на игру, опубликованную через GitHub Pages (или другой HTTPS-хостинг).
- Один проект Supabase; оба игрока используют один и тот же Project URL и публичный `anon` / `publishable` key.
- Не используйте `service_role` key. Его нельзя вставлять в браузер.

### 1. Опубликуйте игру
1. Создайте репозиторий GitHub и загрузите в его корень `index.html`, `style.css`, `app.js`.
2. Откройте репозиторий → **Settings → Pages**.
3. Выберите публикацию из ветки `main`, папка `/ (root)`, сохраните.
4. Дождитесь URL вида `https://username.github.io/repository/`.

### 2. Создайте проект Supabase
1. Создайте проект на https://supabase.com/.
2. В настройках проекта скопируйте **Project URL** и публичный **anon/publishable key**.
3. SQL-таблица для текущей версии не нужна: синхронизация использует Supabase Realtime Broadcast по публичному каналу.

### 3. Подключите Сашу и Диаса
1. Откройте опубликованную игру на устройстве Саши.
2. В блоке «Онлайн-комната» введите URL и публичный ключ Supabase.
3. Выберите «Создать комнату · Саша». Введите короткий код или оставьте поле пустым, чтобы код сгенерировался автоматически.
4. Нажмите «Подключить онлайн», затем «Скопировать ссылку для Диаса» и отправьте ссылку.
5. На устройстве Диаса откройте ссылку. В URL будет записан код комнаты и роль гостя. Введите тот же Supabase URL и публичный ключ, затем нажмите «Подключить онлайн».
6. Когда подключение установлено, Саша начинает новую игру. Управлять ходом может только устройство игрока, чей сейчас ход.

### Ограничения текущей онлайн-версии
- Синхронизация состояния реализована через Realtime Broadcast и предназначена для дружеской игры на двоих; это не серверная защита от читерства.
- Если создатель комнаты закрывает вкладку, гостю может потребоваться переподключение/пересоздание комнаты.
- Состояние комнаты пока не хранится в базе данных: если оба устройства закроют вкладки, прогресс может потеряться.
- Перед первой полноценной партией нужно проверить подключение на двух устройствах и протестировать все модальные сценарии (аукцион, карточки, долги и банкротство).
- Оба игрока должны иметь доступ к интернету. Браузерная игра не требует установки приложения.
